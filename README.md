# Robotic Arm Manipulator (FreeCAD Model)

An open-source 3D model for FreeCAD designed for robotic arm components, starting with the Tool Flange A6.

## Features

* **Tool Flange A6:** Precision-designed mounting flange for robotic end-effectors at coordinates `(0, 0, 280)`.
* **FreeCAD Compatibility:** Provided as a standard `.FCStd` file, ready to view, modify, or export for manufacturing and simulation.

## Requirements

* [FreeCAD](https://www.freecad.org/) (v0.19 or newer)

## Installation & Usage

1. Clone or download this repository.
2. Open FreeCAD.
3. Go to **File -> Open** and select `robotic_arm_manipulator.FCStd` to view and edit the model.
