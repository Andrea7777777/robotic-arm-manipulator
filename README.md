# Robotic Arm Manipulator (FreeCAD Macro)

An open-source Python macro for FreeCAD designed to automatically generate robotic arm components, starting with the Tool Flange A6.

## Features
* **Tool Flange A6**: Automatically generates the robotic end-effector mounting flange at precision coordinates `(0, 0, 280)`.
* Fully compatible with FreeCAD's Python console and macro system.

## Requirements
* [FreeCAD](https://www.freecad.org/) (v0.19 or newer)

## Installation & Usage
1. Open FreeCAD.
2. Go to **Macro** -> **Macros...**.
3. Create a new macro, paste the code from `robotic_arm_manipulator.py`, and click **Execute**.
